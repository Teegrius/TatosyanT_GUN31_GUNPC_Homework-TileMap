# Unity TileMap Homework

## Задание
Создать три карты с использованием Tilemap:
1. Вид сверху (Top-Down)
2. Вид сбоку (Side-View/Platformer)
3. Изометрический вид (Isometric)

На каждую карту добавлен персонаж с управлением.

## Реализация

### 1. Сцена Top-Down
- **Ассеты**: Kenney Pico-8 City
- **Управление**: WASD / Стрелки (4 направления)
- **Особенности**: Вид сверху, движение во всех направлениях

### 2. Сцена Side-View
- **Ассеты**: Kenney Pixel Platformer
- **Управление**: A/D (←→) + Space (прыжок)
- **Особенности**: Платформер с гравитацией и прыжками

### 3. Сцена Isometric
- **Ассеты**: Kenney Isometric Miniature Farm
- **Управление**: WASD / Стрелки
- **Особенности**: Изометрическая проекция, Grid в режиме Isometric
